# 江南 · 烟雨装甲 v2：青岚行动

## 交付状态

这是对 `xiaochenMate/LearnProject` 中 `public/games/jiangnan/` 的增量实现，不是重新搭建网站。保留原 `jiangnan.glb`、`tank.glb`、Three.js、Draco 和工具模块；没有修改网站其他应用、根构建配置、支付或后端功能。

已通过 21 项 Node 逻辑测试；已在 Chromium 中检查 1440×1000、1024×768、390×844、844×390 四种尺寸的 HTML/CSS 布局。测试中修复了首章出生点孤立与增援点过近建筑的问题。

**尚未进行完整 WebGL / 原始 GLB 加载验证、六章人工通关、iPad Safari 真机测试或生产部署验证。** 本环境无法获取运行所需的既有二进制模型及 Three.js 资源。布局测试没有运行游戏引擎；寻路测试使用渲染对象桩，仅验证实际地图生成代码产出的碰撞与路径数据。不得把这些结果描述为“平板流畅性已验证”“全关卡已实测”或“已上线”。

## 地图

地图外框为 224×196 个世界单位（游戏界面以米展示），不是全部可通行土地的面积承诺。中央继续使用原 Blender 水乡模型。新增六区布局：枕河古镇、稻田驿路、竹海电台、运河码头、青石水闸、北山信标。中心运河将南北岸分开，新增两座加固平桥供坦克与工程车通行；保留原台阶拱桥的禁行碰撞。

新增建筑、田埂、树木、岸线、桥梁、控制台和木箱由 `campaign-world.js` 程序生成，使用实例化绘制。没有声称新建了高精度 Blender 模型，也没有修改 `.blend`。原 `surroundings.glb` 不再加载，以免纯背景几何与新开放的陆地互相重叠。

## 六章任务与虚构故事

玩家驾驶救援坦克“青禾”，在虚构的青岚镇协助通讯员许岚、船工周伯和维修师林舟，解除失控无人装甲系统造成的封锁。无真实阵营、真实战争背景或血腥表现。

| 章节 | 核心行动 | 完成条件 |
|---|---|---|
| 雨巷来信 | 清剿并打通出口 | 清除两辆守卫后抵达出口 |
| 稻浪中的回声 | 抢修驿路中继站 | 占点联机 12 秒并清除守卫 |
| 竹海静默 | 切断三座备份终端 | 各终端停留 3 秒并清除守卫 |
| 渡河的人 | 护送工程车 | 活着抵达码头且清除拦路守卫；离玩家超过 30 米即等待 |
| 水闸四十五秒 | 据点守卫 | 累计联机 45 秒，完成两批增援加初始守卫，共三批战斗 |
| 天光归航 | 指挥战车与信标 | 击毁重型目标及护卫，再到信标确认断电 |

占点与守卫进度在离开区域或受到近距离争夺时暂停，不清零。重试从章节起点开始，而非逐帧还原中途状态。

## 实装系统

故事战役、无敌军自由巡游、无尽守卫三种模式；轻松、标准、困难三档难度；侦察、装甲、指挥三类敌军参数；维修、烟幕、短时加速技能；装甲、动力、装填三条车库升级；本机章节解锁、星级和零件存档；地图展开、路线指引、手动路标；敌人血条、装甲命中与装填反馈；暂停、继续、章节重试、视角切换；动态画质降低；键鼠和平板双摇杆、多指开火、失焦清理输入。

三类敌军目前复用同一个坦克 GLB，通过参数、配色和血条区分；工程车也复用该模型，并非全新的专用车辆美术资源。破坏范围限于八个木箱，整栋建筑、桥梁不支持摧毁。没有多人联机、账号云存档、装备商城、任务语音录制或 PWA 离线缓存。

## 工程要点

`campaign-core.js`：无 DOM 的任务状态、存档校验、空间索引、旋转车体碰撞、连续线段命中和二叉堆 A*。

`campaign-world.js`：确定性地图生成；导航与实际碰撞共用数据。网格留出坦克原地转向的空间，过桥路径不跨越水面。

`campaign-engine.js`：复用原 Blender GLB、60 Hz 有上限的固定步长模拟、限量烟尘粒子、分摊 AI 寻路、敌军状态、任务推进及界面绑定。连续线段命中同时比较掩体和坦克，先命中近处对象；从炮塔到炮口做额外遮挡检查。

`index.html`、`campaign.css`：入口与响应式界面。旧 `game.js`、`physics.js`、`style.css` 不删除，便于 Git 回滚；不要直接混用新旧入口中的 DOM 节点。

## 运行与验收

在完整仓库内运行，无须新增游戏运行依赖：

```bash
node --experimental-loader ./tests/jiangnan-campaign/loader.mjs --test ./tests/jiangnan-campaign/campaign.test.mjs
python -m http.server 8765 --directory public
```

浏览器打开 `http://localhost:8765/games/jiangnan/`。游戏路径保留原 `<base>` 配置；必须通过 HTTP/HTTPS 访问，不能双击 HTML 使用 `file://`。代码包不包含既有大模型和引擎资源，需与原仓库 `assets/`、`utils/` 合并使用。

实际 WebGL 冒烟测试脚本：

```bash
pip install playwright
playwright install chromium
python tests/jiangnan-campaign/browser-smoke.py http://localhost:8765/games/jiangnan/
```

此脚本随包提供，尚未在本环境执行成功。运行前需启动上面的 HTTP 服务。

上线前必须补测：GLB 节点与材质加载、六章逐一通关及重试、护送车被挡住后恢复、同时驾驶瞄准按住开火、Safari 切后台恢复、竖横屏切换、无痕模式存档提示、20 分钟连续游戏内存与帧率。不得凭逻辑单测直接认定这些通过。
